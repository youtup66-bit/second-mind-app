# عقلي الثاني

تطبيق PWA عربي يعمل على الجوال: رفيقة صغيرة تتحدث معها صوتاً أو كتابة، فتحفظ كلامك وتصنّفه، وتعرض عقلك ككرات مترابطة.

## المزايا
- **الرفيقة:** شخصية أنمي متحركة تطفو، تحاورك وتقترح حلولاً عملية (Gemini)، وتستعين بما دوّنته سابقاً إن وُجد، وتنطق ردودها بصوت الجهاز أو بصوت Piper العربي داخل التطبيق (دون إنترنت) أو بصوت Gemini.
- **التصنيف التلقائي:** قلق، تفكير، فكرة إبداعية، مهمة، ذكرى، امتنان، حلم، قرار، سؤال — مع تصحيح يدوي.
- **العقل:** كرات حجمها بعدد الملاحظات، وخطوط تقوى بين الأقسام التي تذكرها معاً، مع إمكانية إضافة أقسام خاصة بك (حتى ١٢) يصنّف فيها Gemini تلقائياً.
- **المجلد:** بحث وتصفية، إنجاز المهام، وملخصات لليوم/الأسبوع/الشهر أو لقسم بعينه.
- **النسخ الاحتياطي:** تصدير واستيراد ZIP، ولقطات يومية تلقائية على الجهاز.

## الخصوصية
كل البيانات في IndexedDB على جهازك. يُرسل إلى Gemini فقط: نص المحادثة الأخيرة، وتسجيلك الصوتي لتحويله إلى نص عند استخدام 🎙 (لا يُحفظ)، وأقرب ٥ ملاحظات صلة برسالتك (يُبحث عنها محلياً، ويمكن إيقاف ذلك)، والملاحظة لتصنيفها، وملاحظات الفترة عند طلب ملخص، ونص رد الرفيقة إن اخترت صوت Gemini الطبيعي. مفتاح API يبقى على الجهاز ولا يدخل ملفات النسخ الاحتياطي.
