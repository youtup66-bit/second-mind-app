# عقلي الثاني

تطبيق PWA عربي يعمل على الجوال: رفيقة صغيرة تتحدث معها صوتاً أو كتابة، فتحفظ كلامك وتصنّفه، وتعرض عقلك ككرات مترابطة.

## المزايا
- **الرفيقة:** شخصية أنمي متحركة تطفو، تستمع وتفكر وتردّ (Gemini)، وتنطق ردودها.
- **التصنيف التلقائي:** قلق، تفكير، فكرة إبداعية، مهمة، ذكرى، امتنان، حلم، قرار، سؤال — مع تصحيح يدوي.
- **العقل:** كرات حجمها بعدد الملاحظات، وخطوط تقوى بين الأقسام التي تذكرها معاً.
- **المجلد:** بحث وتصفية، إنجاز المهام، وملخصات لليوم/الأسبوع/الشهر أو لقسم بعينه.
- **النسخ الاحتياطي:** تصدير واستيراد ZIP، ولقطات يومية تلقائية على الجهاز.

## الخصوصية
كل البيانات في IndexedDB على جهازك. يُرسل إلى Gemini فقط: نص المحادثة الأخيرة، والملاحظة لتصنيفها، وملاحظات الفترة عند طلب ملخص. مفتاح API يبقى على الجهاز ولا يدخل ملفات النسخ الاحتياطي.

## التشغيل محلياً
```
python3 -m http.server 8000
```
ثم افتح http://localhost:8000
