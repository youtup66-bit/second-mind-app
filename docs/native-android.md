# تطبيق الملاحظات الأصلي (أندرويد، Kotlin)

المجلد: `native/`. تطبيق مستقل عن نسخة الويب، مكتوب بـ Kotlin وJetpack Compose، وكل بياناته على الهاتف (SQLite).

## الفكرة
- واجهة محادثة تشبه برامج الذكاء الصناعي.
- ذكاء صناعي يعمل على الهاتف نفسه، يختار المستخدم نموذجاً أو أكثر.
- يحفظ كل المحادثات، ويستعين بها في ردوده (ذاكرة).
- «العقل»: أقسام على شكل كرات بأيقونات، والكرة تفتح كتاباً تُقلب صفحاته (صفحة لكل ملاحظة).
- يقسّم الملاحظات ويضعها في أقسام تلقائياً، مع إمكانية النقل يدوياً وإضافة أقسام.

## المراحل
| # | المرحلة | الحالة |
|---|---------|--------|
| ١ | الهيكل: المحادثة، العقل بالكرات، الكتاب، التخزين المحلي، تصنيف وذاكرة مبدئيان بالكلمات | ✅ |
| ٢ | نماذج على الهاتف: شاشة اختيار وتنزيل (Gemma وQwen عبر MediaPipe LLM Inference) | ⏳ |
| ٣ | التصنيف بالنموذج المحلي بدل الكلمات، وتلخيص كل كتاب | ⏳ |
| ٤ | ذاكرة أعمق: بحث دلالي (embeddings) في كل المحادثات | ⏳ |
| ٥ | الإدخال الصوتي، وخط Tajawal، والتصدير والاستيراد والنسخ الاحتياطي | ⏳ |

## البناء
يُبنى تلقائياً عند كل دفع يغيّر `native/` (سير العمل "Native notes app")، وملف APK في Artifacts صفحة التشغيل.
محلياً (مع Android SDK): `cd native && gradle :app:assembleDebug`.
