# Note AI — تطبيق الملاحظات الأصلي (أندرويد، Kotlin)

المجلد: `native/`. تطبيق مستقل عن نسخة الويب، مكتوب بـ Kotlin وJetpack Compose، وكل بياناته على الهاتف (SQLite).

## الفكرة
- واجهة محادثة تشبه برامج الذكاء الصناعي.
- ذكاء صناعي يعمل على الهاتف نفسه، يختار المستخدم نموذجاً أو أكثر، أو Gemini على الإنترنت بمفتاح يُحفظ على الهاتف فقط (اختياري، مع تنبيه خصوصية).
- يحفظ كل المحادثات، ويستعين بها في ردوده (ذاكرة).
- «العقل»: شبكة كرات تتحرك بحرية (محاكاة فيزيائية)؛ العقل في الوسط، والأقسام حوله، والملاحظات حول أقسامها، والخطوط تربط ما بينها كلمات مشتركة (اقتراح آلي). القسم يفتح كتاباً تُقلب صفحاته، والملاحظة تفتح صفحتها.
- يقسّم الملاحظات ويضعها في أقسام تلقائياً، مع إمكانية النقل يدوياً وإضافة أقسام.

## المراحل
| # | المرحلة | الحالة |
|---|---------|--------|
| ١ | الهيكل: المحادثة، العقل بالكرات، الكتاب، التخزين المحلي، تصنيف وذاكرة مبدئيان بالكلمات | ✅ |
| ٢ | نماذج على الهاتف: شاشة اختيار وتنزيل واستيراد (Gemma وQwen عبر MediaPipe LLM Inference) | ✅ |
| ٣ | التصنيف بالنموذج المحلي بدل الكلمات (والكلمات احتياط)، وتلخيص كل كتاب على غلافه | ✅ |
| ٤ | ذاكرة بالمعنى: نموذج MiniLM متعدد اللغات (ONNX) يعطي كل ملاحظة بصمة معنى؛ التذكّر وروابط العقل بالمعنى، والكلمات المشتركة احتياط | ✅ |
| ٥ | النسخ الاحتياطي: مجلد يختاره المستخدم، ونسخ تلقائي كل ٢٤ ساعة (WorkManager)، ونسخ يدوي، واستعادة | ✅ |
| ٦ | الإدخال الصوتي، وخط Tajawal | ⏳ |

## البناء
يُبنى تلقائياً عند كل دفع يغيّر `native/` (سير العمل "Native notes app")، وملف APK في Artifacts صفحة التشغيل.
محلياً (مع Android SDK): `cd native && gradle :app:assembleDebug`.
